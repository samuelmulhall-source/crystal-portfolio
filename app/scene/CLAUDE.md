# Scene Contract

- Scene work is optional enhancement, not a prerequisite for understanding the portfolio.
- Never make a fullscreen canvas the primary navigation or archive surface for the main site.
- Keep scene systems gated by visibility, explicit intent, and display-mode budget.
- Reusable modules are preferred over a single global journey state machine.
- Any future specimen preview should derive from typed project content, not hardcoded order or IDs.
- Reduced mode must remain coherent:
  - no broken compositions
  - no blank sections
  - no hidden content
- If a scene system cannot justify its cost against clearer project presentation, do not ship it.
